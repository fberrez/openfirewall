# Product

## Register

product

## Users

Mac users who want to see which apps connect to the internet and decide which can connect. The interface serves both a quick check of firewall status and a closer inspection of recent connections.

## Product Purpose

OpenFirewall is a free, MIT-licensed macOS firewall. It provides per-app Allow and Block rules, a configurable default, and a local connection monitor. It requires no account or subscription. Rules and connection metadata stay on the Mac.

## Brand Personality

Technical, independent, direct. Use short, concrete labels. Explain security state accurately. The user explicitly chose app.nymchat.com as the reference and requested a stronger hacker and nerd aesthetic: a phosphor-green terminal, monospaced typography, and square frames.

## Anti-references

Avoid rounded SaaS dashboards, decorative statistics, marketing claims inside task flows, cartoon mascots, fake terminal activity, and effects that obscure connection data. Do not reproduce Nymchat's identity or claims.

## Design Principles

- Make firewall state and the next useful action easy to find.
- Keep app identity, connection destination, and decision easy to compare.
- Keep native macOS controls and keyboard behavior familiar.
- Explain the difference between explicit app rules and the default.
- Keep monitoring local and retain existing rules through interface changes.

## Accessibility & Inclusion

Use native accessible controls and system monospaced typography. Pair state colors with text or symbols. Preserve keyboard focus, readable contrast, reduced-motion behavior, and light/dark appearance. No additional accessibility needs have been specified.
